# Ethiopidia Content Schema

**Scope:** Destinations, destination detail content, Things to Do, categories, galleries, guides, schedules, services, menus, and tour itineraries.

## 1. Entity relationship

```text
destinations
├── destination_gallery
├── destination_guide_sections
└── things_to_do
    ├── thing_to_do_categories
    ├── thing_to_do_gallery
    ├── thing_to_do_guide_sections
    ├── thing_to_do_menu_items
    ├── thing_to_do_services
    ├── thing_to_do_schedule
    └── thing_to_do_itinerary
```

Relationship rules:

- One destination has zero or many gallery images.
- One destination has zero or many ordered guide sections.
- One destination has zero or many Things to Do.
- One Thing to Do belongs to exactly one destination.
- One Thing to Do belongs to exactly one category.
- One Thing to Do can have gallery, guide, menu, service, schedule, and itinerary child records.
- Deleting a destination cascades to its gallery and guide sections.
- A destination cannot be deleted while it has Things to Do. Its activities must be reassigned or deleted first.
- Deleting a Thing to Do cascades to all of its child content.

## 2. Shared conventions

### 2.1 Languages

All traveler-facing text supports:

- English: fields ending in `_en`
- Amharic: fields ending in `_am`

Both versions are required for publishing core titles and descriptions. Optional subtitles and captions may be empty in both languages.

### 2.2 Publishing status

```text
draft      Record is visible only to authorized content managers.
published  Record is visible on public pages and APIs.
archived   Record is retained but hidden from public pages.
```

### 2.3 Identifiers and dates

- Primary identifiers are UUID values generated by PostgreSQL.
- All managed records include `created_at`.
- Mutable primary records include `updated_at`.
- All timestamps use UTC-aware `TIMESTAMPTZ`.
- Public detail entities use a unique URL-safe `slug`.

## 3. PostgreSQL schema

The following schema targets PostgreSQL 15 or later.

```sql
BEGIN;

CREATE EXTENSION IF NOT EXISTS pgcrypto;

CREATE TYPE content_status AS ENUM ('draft', 'published', 'archived');
CREATE TYPE image_position AS ENUM ('left', 'right', 'full');
CREATE TYPE schedule_frequency AS ENUM ('once', 'daily', 'weekly', 'monthly', 'seasonal');

CREATE OR REPLACE FUNCTION set_updated_at()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- =========================================================
-- DESTINATIONS
-- =========================================================

CREATE TABLE destinations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug VARCHAR(160) NOT NULL UNIQUE,
  name_en VARCHAR(160) NOT NULL,
  name_am VARCHAR(160) NOT NULL,
  region_en VARCHAR(160),
  region_am VARCHAR(160),
  tagline_en VARCHAR(220),
  tagline_am VARCHAR(220),
  short_description_en TEXT NOT NULL,
  short_description_am TEXT NOT NULL,
  long_description_en TEXT,
  long_description_am TEXT,
  hero_image TEXT NOT NULL,
  hero_alt_en VARCHAR(300),
  hero_alt_am VARCHAR(300),
  card_image TEXT,
  best_time_en TEXT,
  best_time_am TEXT,
  latitude NUMERIC(9, 6),
  longitude NUMERIC(9, 6),
  is_iconic BOOLEAN NOT NULL DEFAULT FALSE,
  status content_status NOT NULL DEFAULT 'draft',
  sort_order INTEGER NOT NULL DEFAULT 0,
  seo_title_en VARCHAR(70),
  seo_title_am VARCHAR(70),
  seo_description_en VARCHAR(170),
  seo_description_am VARCHAR(170),
  social_image TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  CONSTRAINT destinations_slug_format
    CHECK (slug ~ '^[a-z0-9]+(?:-[a-z0-9]+)*$'),
  CONSTRAINT destinations_name_en_not_blank
    CHECK (LENGTH(BTRIM(name_en)) > 0),
  CONSTRAINT destinations_name_am_not_blank
    CHECK (LENGTH(BTRIM(name_am)) > 0),
  CONSTRAINT destinations_description_en_not_blank
    CHECK (LENGTH(BTRIM(short_description_en)) > 0),
  CONSTRAINT destinations_description_am_not_blank
    CHECK (LENGTH(BTRIM(short_description_am)) > 0),
  CONSTRAINT destinations_latitude_range
    CHECK (latitude IS NULL OR latitude BETWEEN -90 AND 90),
  CONSTRAINT destinations_longitude_range
    CHECK (longitude IS NULL OR longitude BETWEEN -180 AND 180),
  CONSTRAINT destinations_sort_order_nonnegative
    CHECK (sort_order >= 0)
);

CREATE INDEX destinations_public_order_idx

CREATE INDEX destinations_name_en_search_idx
```

## 5. API schema

All mutation endpoints require an authenticated editor or administrator. Protected calls send:

```http
Authorization: Bearer {access_token}
Content-Type: application/json
```

### 5.1 Destinations

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/cities` | Paginated destination list |
| POST | `/cities` | Create destination |
| GET | `/cities/{id}` | Destination detail by ID |
| PATCH | `/cities/{id}` | Partially update destination |
| DELETE | `/cities/{id}` | Delete destination |
| GET | `/cities/slug/{slug}` | Public destination detail by slug |
| GET | `/cities/{id}/gallery` | List gallery images |
| POST | `/cities/{id}/gallery` | Add gallery image |
| PATCH | `/cities/{id}/gallery/reorder` | Reorder gallery |
| DELETE | `/cities/{id}/gallery/{imageId}` | Delete gallery image |
| GET | `/cities/{id}/guides` | List guide sections |
| POST | `/cities/{id}/guides` | Create guide section |
| PATCH | `/cities/{id}/guides/{guideId}` | Update guide section |
| DELETE | `/cities/{id}/guides/{guideId}` | Delete guide section |

Destination list query parameters:

```text
q            Search English and Amharic names/descriptions
iconic       true or false
status       draft, published, or archived; protected
page         Positive integer; default 1
page_size    1–100; default 20
sort         sort_order, name, newest, or updated
```

### 5.2 Categories

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/thing-to-do-categories` | List active categories |
| POST | `/thing-to-do-categories` | Create category |
| GET | `/thing-to-do-categories/{id}` | Get category |
| PATCH | `/thing-to-do-categories/{id}` | Update category |
| DELETE | `/thing-to-do-categories/{id}` | Delete unused category |

Category deletion returns `409 Conflict` when Things to Do still use it.

### 5.3 Things to Do

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/things-to-do` | Filtered, paginated activity list |
| POST | `/things-to-do` | Create activity |
| GET | `/things-to-do/{id}` | Activity detail by ID |
| PATCH | `/things-to-do/{id}` | Partially update activity |
| DELETE | `/things-to-do/{id}` | Delete activity and child records |
| GET | `/things-to-do/slug/{slug}` | Public activity detail by slug |
| GET | `/cities/{cityId}/things-to-do` | Activities for one destination |

List query parameters:

```text
q             Search title and description
city_id       Filter by destination
category_id   Filter by category
featured      true or false
free          true or false
status        draft, published, or archived; protected
page          Positive integer; default 1
page_size     1–100; default 20
sort          recommended, newest, name, or price
```

Child endpoints follow the same pattern:

```text
/things-to-do/{id}/gallery
/things-to-do/{id}/guides
/things-to-do/{id}/menu-items
/things-to-do/{id}/services
/things-to-do/{id}/schedule
/things-to-do/{id}/itinerary
```

Each collection supports `GET` and `POST`. Each child record supports `PATCH` and `DELETE` using `/{childId}`. Ordered collections also support `PATCH /reorder`.

## 6. JSON request examples

### 6.1 Create a basic destination

This is compatible with the current `/cities` frontend form.

```json
{
  "name_en": "Addis Ababa",
  "name_am": "አዲስ አበባ",
  "description_en": "Capital city of Ethiopia",
  "description_am": "የኢትዮጵያ ዋና ከተማ",
  "hero_image": "https://example.com/city.jpg",
  "is_iconic": true
}
```

The backend maps `description_en` and `description_am` to `short_description_en` and `short_description_am` while the basic contract is supported.

### 6.2 Create a complete destination


### 7.1 Paginated list

```json

  "items": [],
  "page": 1,
  "page_size": 20,
  "total": 0,
  "page_count": 0
}
```

### 7.2 Single record

```json
{
  "data": {}
}
```

### 7.3 Validation error

```json
{
  "code": "VALIDATION_ERROR",
  "message": "The submitted data is invalid.",
  "fields": {
    "name_am": "Amharic name is required."
  }
}
```

### 7.4 HTTP status rules

| Status | Use |
|---:|---|
| `200 OK` | Successful read or update |
| `201 Created` | Successful create |
| `204 No Content` | Successful delete |
| `400 Bad Request` | Invalid JSON or query syntax |
| `401 Unauthorized` | Missing or expired token |
| `403 Forbidden` | User lacks permission |
| `404 Not Found` | Record does not exist |
| `409 Conflict` | Duplicate slug or protected relationship |
| `422 Unprocessable Entity` | Field validation failure |
| `500 Internal Server Error` | Unexpected server failure |

## 9. Publication validation

A destination can be published only when it has:

- English and Amharic names
- Unique valid slug
- English and Amharic short descriptions
- English and Amharic long descriptions
- Hero image
- English and Amharic hero alternative text
- At least one guide section is recommended but not required

A Thing to Do can be published only when it has:

- Existing destination
- Active category
- English and Amharic titles
- Unique valid slug
- English and Amharic short descriptions
- English and Amharic long descriptions
- Hero image
- English and Amharic hero alternative text
- Valid coordinates, URLs, prices, and duration when provided

## 10. Admin editor modules

### Destination editor

1. Basic information
2. English and Amharic descriptions
3. Hero image and gallery
4. Guide sections
5. Best time and location
6. Linked Things to Do
7. SEO and publishing

### Things-to-Do editor

1. Destination and category
2. Basic information
3. English and Amharic descriptions
4. Hero image and gallery
5. Guide sections
6. Address, map, opening hours, duration, and price
7. Menu, services, schedule, or itinerary when relevant
8. Booking, SEO, and publishing

### Category editor

1. English and Amharic name
2. Slug
3. English and Amharic description
4. Icon and cover image
5. Display order and active status
